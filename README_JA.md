## 🖥️ デスクトップ体験 (Windows)

Tauri 2、Rust、React 19で構築されたサイドバー主導の快適な制作環境。アカウント不要、クラウドラグなし、音質劣化ゼロでPC上でローカル動作します。

<br />

### 1. ホーム・ダッシュボード
すべてのツールを「ダウンロード」「作成」「編集・解析」に整理。クイックヒントと更新履歴カルーセルを搭載。

<p align="center">
  <img src="docs/screenshots/ana-sayfa.png" alt="ホーム・ダッシュボード" width="100%" />
</p>

<br />

### 2. Suno Downloader 2.0
Sunoリンクを貼り付けてスタジオ品質の320kbps MP3、可逆WAV、またはオリジナル音源を取得。高解像度アートワークと同期歌詞（.lrc/.txt）を自動でファイルに埋め込みます。

<p align="center">
  <img src="docs/screenshots/sophy-downloader.png" alt="Suno Downloader 2.0" width="100%" />
</p>

<br />

### 3. Universal Media Downloader
YouTube、Instagram、TikTok、Facebook、X（Twitter）、RedditなどからワンクリックでMP4動画または320k MP3音声をダウンロード。

<p align="center">
  <img src="docs/screenshots/universal-downloader.png" alt="Universal Media Downloader" width="100%" />
</p>

<br />

### 4. Suno Style Prompter
自然な言葉で楽曲のイメージを伝えるだけで、Suno用のStyle of Musicタグや[Intro]、[Verse]、[Chorus]などの構成タグを自動生成。オフラインで動作します。

<p align="center">
  <img src="docs/screenshots/prompter.png" alt="Suno Style Prompter" width="100%" />
</p>

<br />

### 5. Sample Cutter（8秒スライサー）
音源を読み込み、8.0秒のループ枠を波形上でスライドしてリアルタイム試聴。320k MP3またはWAVとして書き出せます。

<p align="center">
  <img src="docs/screenshots/sample-cutter.png" alt="Sample Cutter（8秒スライサー）" width="100%" />
</p>

<br />

### 6. オーディオ・メタデータエディタ
MP3、WAV、FLAC、M4Aのタイトル、アーティスト、アルバム、年、ジャンルを編集し、カバーアートをID3v2.3形式で直接埋め込みます。

<p align="center">
  <img src="docs/screenshots/metadata-editor.png" alt="オーディオ・メタデータエディタ" width="100%" />
</p>

<br />

### 7. キー ＆ BPM 検出
音源をドロップするだけでキー、キャメロットホイール位置（例: 8B / ハ長調）、テンポ（BPM）を即座に検出。オフラインでEssentia.jsが解析します。

<p align="center">
  <img src="docs/screenshots/bpm-detect.png" alt="キー ＆ BPM 検出" width="100%" />
</p>

<br />

### 8. デスクトップ設定 ＆ カスタマイズ
9つのカラーテーマ、360°カラーピッカー、文字・表示サイズ拡大（90%〜150%）、8言語対応を搭載。

<p align="center">
  <img src="docs/screenshots/appearance.png" alt="デスクトップ設定 ＆ カスタマイズ" width="100%" />
</p>

#### 📥 Windows版 Sophy Studio のダウンロード
1. 最新リリースから **`Sophy_Studio_Setup.exe`** をダウンロードします。
2. インストーラーを実行します。管理者権限は不要です。
3. スタートメニューまたはデスクトップのショートカットから起動します。

## 📱 モバイル体験 (Android)

Sophy Studio Mobileは、デスクトップ版と同じホームから設定までの直感的な順序でスマートフォンに完全な制作機能を提供します。

<br />

### 1. モバイル・ホームダッシュボード
手のひらのスタジオ司令塔。すべてのダウンローダーや作成ツールに快適なカードUIで即座にアクセス。

<p align="center">
  <img src="docs/m-screenshots/m-homepage.jpg" alt="モバイル・ホームダッシュボード" width="45%" />

<p align="center">
  <img src="docs/m-screenshots/m-sunodownloader.jpg" alt="モバイル Suno Downloader" width="45%" />

## 🛠️ Technology Stack / Architektur

| Component | Desktop (Windows) | Mobile (Android) |
|---|---|---|
| **Shell & Runtime** | Tauri 2 · Rust | Capacitor / Tauri Android |
| **Frontend UI** | React 19 · TypeScript · Tailwind CSS 4 · Vanilla CSS | React 19 · TypeScript · Touch Gestures |
| **Audio Processing** | FFmpeg · lofty / id3 · Essentia.js (WASM) | Web Audio API · Essentia.js (WASM) |
| **Download Engine** | Native Suno Client · yt-dlp binary | Suno API Client · Extractor Service |
| **Offline AI Model** | llama.cpp · Qwen2.5-1.5B-Instruct (Q4_K_M) | Multilingual Natural Language Rule Engine |
| **Packaging** | NSIS Per-User Installer (`.exe`) | Android Package (`.apk`) |
