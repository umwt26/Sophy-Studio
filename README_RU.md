## 🖥️ Версия для ПК (Windows)

Версия для ПК предоставляет удобную студийную среду с боковой панелью на базе Tauri 2, Rust и React 19. Все процессы работают локально на вашем ПК без очередей, учетных записей и потери качества звука.

<br />

### 1. Главная панель управления
Все инструменты разбиты по категориям: Скачивание, Создание и Обработка & Анализ, дополненные быстрыми советами и списком обновлений.

<p align="center">
  <img src="docs/screenshots/ana-sayfa.png" alt="Главная панель управления" width="100%" />
</p>

<br />

### 2. Suno Downloader 2.0
Вставьте ссылку Suno и скачайте трек в студийном качестве MP3 320 кбит/с, lossless WAV или исходный поток. Автоматически извлекает и вшивает обложку высокого разрешения и текст песни (.lrc / .txt).

<p align="center">
  <img src="docs/screenshots/sophy-downloader.png" alt="Suno Downloader 2.0" width="100%" />
</p>

<br />

### 3. Universal Media Downloader
Скачивайте видео или аудио с YouTube, Instagram, TikTok, Facebook, X (Twitter), Reddit и сотен других платформ в формате MP4 или MP3 320k в один клик.

<p align="center">
  <img src="docs/screenshots/universal-downloader.png" alt="Universal Media Downloader" width="100%" />
</p>

<br />

### 4. Suno Style Prompter
Опишите песню своими словами на любом из 8 языков и получите готовые теги Style of Music и структуру песни ([Intro], [Verse], [Chorus], [Outro]). Работает полностью офлайн.

<p align="center">
  <img src="docs/screenshots/prompter.png" alt="Suno Style Prompter" width="100%" />
</p>

<br />

### 5. Sample Cutter (8-секундный слайсер)
Загрузите трек, перемещайте 8-секундное окно петли по звуковой волне и экспортируйте в MP3 320k или WAV для продолжения треков в Suno.

<p align="center">
  <img src="docs/screenshots/sample-cutter.png" alt="Sample Cutter (8-секундный слайсер)" width="100%" />
</p>

<br />

### 6. Редактор метаданных аудио
Редактируйте название, исполнителя, альбом, год, жанр и вшивайте обложки альбомов прямо в файлы MP3, WAV, FLAC и M4A по стандарту ID3v2.3.

<p align="center">
  <img src="docs/screenshots/metadata-editor.png" alt="Редактор метаданных аудио" width="100%" />
</p>

<br />

### 7. Определение тональности (Key) и BPM
Перетащите аудиофайл, чтобы определить тональность, позицию на колесе Camelot (например, 8B / До мажор) и точный темп с регулировкой (-1, +1, /2, *2).

<p align="center">
  <img src="docs/screenshots/bpm-detect.png" alt="Определение тональности (Key) и BPM" width="100%" />
</p>

<br />

### 8. Настройки и персонализация ПК
Настройте Sophy Studio: 9 цветовых тем, палитра 360°, масштабирование текста и интерфейса (90%–150%) и поддержка 8 языков.

<p align="center">

</p>

## 📱 Мобильная версия (Android)

<br />

### 1. Главная панель на смартфоне
Мобильный центр управления студией. Мгновенный доступ ко всем загрузчикам и инструментам с помощью удобных карточек.

## 🛠️ Technology Stack / Architektur

| Component | Desktop (Windows) | Mobile (Android) |
|---|---|---|
| **Shell & Runtime** | Tauri 2 · Rust | Capacitor / Tauri Android |
| **Frontend UI** | React 19 · TypeScript · Tailwind CSS 4 · Vanilla CSS | React 19 · TypeScript · Touch Gestures |
| **Audio Processing** | FFmpeg · lofty / id3 · Essentia.js (WASM) | Web Audio API · Essentia.js (WASM) |
| **Download Engine** | Native Suno Client · yt-dlp binary | Suno API Client · Extractor Service |
| **Offline AI Model** | llama.cpp · Qwen2.5-1.5B-Instruct (Q4_K_M) | Multilingual Natural Language Rule Engine |
| **Packaging** | NSIS Per-User Installer (`.exe`) | Android Package (`.apk`) |
